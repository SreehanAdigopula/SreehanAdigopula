# Maintaining this profile

The root README appears automatically at github.com/SreehanAdigopula because this public repository matches the account username.

- Edit `README.md` to change the introduction, featured projects, or tool list.
- Edit `assets/header.svg` to change the name banner or its colors.
- The activity image is generated by `scripts/update_activity.py`, using only GitHub's public repository API. No personal access token or third-party image service is needed.
- The dashboard shows public repository totals, original repository totals, primary language counts, and five recently pushed original projects. It excludes forks, archived repositories, and this profile repository from the language and recent-project lists. These are repository metadata, not personal commit or contribution counts.
- The workflow runs daily at 11:23 UTC and can also be started from **Actions → Refresh profile dashboard → Run workflow**. GitHub may delay scheduled runs or disable scheduled workflows after 60 days of repository inactivity; the dated snapshot remains visible in the meantime. Check the Actions tab if it stops refreshing.
- The workflow uses GitHub's built-in token with repository contents write permission to commit `assets/activity.svg`. It does not call an external stats service.
- If the image needs an immediate refresh locally, run `python3 scripts/update_activity.py` and commit the changed SVG.
- Keep project URLs current and avoid adding unsupported claims about users, awards, security, or model accuracy.

The visual direction uses a dark workshop canvas, warm amber labels, teal accents, and simple diagrams. Native GitHub Markdown keeps the main content readable in light and dark themes. Custom images are stored in this repository.
